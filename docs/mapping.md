# Mapping Reference

Generated by `npm run docs:generate` from the rule catalog (`src/core/rules.ts`) and the mapping tables (`src/sources/cypress-js/table.ts` and `src/sources/selenium/common.ts`). Do not edit it by hand. A unit test fails when this file and the tables differ.

The Playwright column is printed by the same emitter that `migrate` uses, with `#element` as the sample locator. Navigation, locator chains and test structure are converted by the extractors and are covered by the fixtures and tests, not by these tables.

## Rules

Every flag in a migration report has one of these rule IDs. INFO means the step was converted with a note. WARN means it was converted but needs a look. BLOCK means it was not converted, and the test is emitted as `test.fixme`.

| Rule                          | Level | Applies to               | Title                         | Message                                                                                                                                                                       |
| ----------------------------- | ----- | ------------------------ | ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `CORE_UNKNOWN_STATEMENT`      | BLOCK | All sources              | Unrecognized statement        | Statement not recognized, so it was not converted. Convert it by hand.                                                                                                        |
| `CORE_UNSUPPORTED_LOCATOR`    | BLOCK | All sources              | Unsupported locator           | Locator {detail} is not supported in v0.1. Convert it by hand.                                                                                                                |
| `CORE_UNSUPPORTED_ASSERTION`  | BLOCK | All sources              | Unsupported assertion         | Assertion {detail} is not supported in v0.1. Convert it by hand.                                                                                                              |
| `CORE_UNSUPPORTED_MEMBER`     | BLOCK | Selenium Python and Java | Unsupported class member      | Class member {detail} is not converted. Move shared setup into a hook or a fixture by hand.                                                                                   |
| `CORE_FIXED_WAIT`             | WARN  | All sources              | Fixed wait kept               | Fixed wait kept. Replace it with a web-first assertion on the condition the test needs.                                                                                       |
| `CORE_CUSTOM_WAIT`            | BLOCK | Selenium Python and Java | Custom wait condition         | Wait with a custom condition is not converted. Rewrite it as a web-first assertion.                                                                                           |
| `CORE_FRAME`                  | BLOCK | Selenium Python and Java | Frame switching               | Frame switching is not converted. Use page.frameLocator for the steps inside the frame.                                                                                       |
| `CORE_WINDOW`                 | BLOCK | Selenium Python and Java | Window, tab or alert handling | Window, tab or alert handling is not converted. Use Playwright popup, page or dialog events.                                                                                  |
| `CORE_JS_EXECUTOR`            | BLOCK | Selenium Python and Java | JavaScript executor           | JavaScript executor calls are not converted. Use a Playwright action, or page.evaluate after review.                                                                          |
| `CORE_FILL_REPLACES_VALUE`    | INFO  | All sources              | Typing converted to fill      | Typing was converted to fill, which replaces the field value in one step. Use pressSequentially if the app needs key events.                                                  |
| `CORE_XPATH`                  | INFO  | All sources              | XPath kept                    | XPath locator kept. XPath does not pierce shadow DOM.                                                                                                                         |
| `CORE_TEXT_LOCATOR`           | INFO  | All sources              | Text locator                  | Text or link text locator converted to a text or accessible name match. Check that it matches exactly one element.                                                            |
| `CORE_DRIVER_LIFECYCLE`       | INFO  | Selenium Python and Java | Driver setup removed          | WebDriver setup or teardown removed. The Playwright page fixture replaces it.                                                                                                 |
| `CORE_WAIT_OBJECT`            | INFO  | Selenium Python and Java | Wait object removed           | WebDriverWait object removed. Playwright actions and web-first assertions wait on their own.                                                                                  |
| `CORE_IMPLICIT_WAIT`          | INFO  | Selenium Python and Java | Implicit wait removed         | Implicit wait removed. Playwright waits for elements to be actionable.                                                                                                        |
| `CORE_CLICKABLE_WAIT_REMOVED` | INFO  | Selenium Python and Java | Clickable wait removed        | Wait for clickable removed, because the next action waits for the same element.                                                                                               |
| `CORE_STORED_ELEMENT`         | INFO  | Selenium Python and Java | Stored element                | Stored element became a lazy locator. It is looked up again each time it is used.                                                                                             |
| `CORE_WINDOW_SIZE`            | INFO  | Selenium Python and Java | Window size removed           | Window size or maximize call removed. Set the viewport in playwright.config.ts if needed.                                                                                     |
| `CORE_ASSERT_MESSAGE_DROPPED` | INFO  | Selenium Python and Java | Assertion message dropped     | Assertion message dropped. Playwright prints the locator and expected value on failure.                                                                                       |
| `CY_CUSTOM_COMMAND`           | BLOCK | Cypress JS               | Custom command                | Custom command cy.{name} is not converted. Port it to a helper function or a fixture.                                                                                         |
| `CY_INTERCEPT`                | BLOCK | Cypress JS               | Network intercept             | cy.intercept is not converted. Rewrite it with page.route or page.waitForResponse, registered before the action that sends the request.                                       |
| `CY_ALIAS`                    | BLOCK | Cypress JS               | Alias                         | Cypress aliases (.as and cy.wait('@alias')) are not converted. Keep a variable or a page.waitForResponse promise instead.                                                     |
| `CY_THEN`                     | BLOCK | Cypress JS               | Callback                      | Callbacks (.then, .each, .spread, should with a function) are not converted. Rewrite the callback with locators and expect.                                                   |
| `CY_UNSUPPORTED_COMMAND`      | BLOCK | Cypress JS               | Unsupported Cypress command   | Cypress command .{name}() has no safe Playwright mapping in v0.1. Convert this step by hand.                                                                                  |
| `CY_BEFORE_HOOK`              | BLOCK | Cypress JS               | Run-once hook                 | before and after hooks are not converted, because Playwright beforeAll and afterAll hooks cannot use the page fixture. Move these steps into beforeEach or afterEach by hand. |
| `CY_WITHIN`                   | INFO  | Cypress JS               | Within scope inlined          | cy.within scope was inlined into the locator chain.                                                                                                                           |
| `CY_ONLY`                     | WARN  | Cypress JS               | Exclusive test                | {name}.only was converted to a normal {name}, because Playwright test.only would skip every other test in the run. Add .only back by hand if you need it.                     |
| `PY_MAIN_GUARD`               | INFO  | Selenium Python          | Main guard removed            | The if \_\_name\_\_ == "\_\_main\_\_" block was removed. Playwright Test runs the specs.                                                                                      |

## Cypress JS Callbacks

`.then()`, `.each()`, `.spread()` and `should` with a function are blocked with `CY_THEN`. A `cy.<name>` call that is not a built-in Cypress command is blocked with `CY_CUSTOM_COMMAND`, and a built-in command with no mapping is blocked with `CY_UNSUPPORTED_COMMAND`.
