# Evaluation Bar: Demo Suites, Oct 30, 2026

Written before the first `verify` run. The results go to `evals/2026-10-30-results.md`, and any run that misses this bar is recorded there as a miss.

## What Runs

- Demo suites: the six SauceDemo cases in `fixtures/saucedemo/cases` (login success, locked out user, add to cart, cart badge, checkout complete, sort products), converted once per source with `migrate fixtures/saucedemo/cases --from <framework>`. That gives three suites of six specs: Cypress JS, Selenium Python and Selenium Java.
- Flag fixtures: the whole `fixtures/saucedemo` folder converted in one run, including the 15 flag fixtures.
- Each converted folder is checked with `playwright-migrate verify <folder>`, which runs `playwright test --repeat-each=5` in Chromium with retries 0.

## The Bar

1. Every demo suite converts with exit code 0: 6 files, all `converted`, no WARN and no BLOCK flags.
2. Every converted demo spec passes 5 of 5 runs: 30 passed runs per suite, 0 failed, 0 skipped.
3. In the whole fixtures folder, every test that is not blocked or skipped passes 5 of 5 runs, and every blocked test is skipped (`test.fixme`), never passed and never failed.
4. `verify` writes the run counts into `migration-report.json` and `migration-report.md`, and its exit code is 0 only when no run failed.
5. Nothing in this evaluation uses client code. All tests run against https://www.saucedemo.com.

## Not Measured

- Speed, other browsers, and real projects outside the fixtures.
